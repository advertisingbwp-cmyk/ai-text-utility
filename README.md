# AI Smart Text Utility & Assistant

A modern, fast, and free web application providing instant text transformations and AI-powered grammar & tone enhancements.

## 🚀 Features

### 1. Real-time Live Counters
- Total Words
- Total Characters (with & without spaces)
- Sentences & Paragraphs
- Estimated Reading Time

### 2. Browser-based Text Tools (Instant, Zero Latency)
- UPPERCASE, lowercase, Title Case, Sentence case, camelCase
- Clean/Trim extra spaces & duplicate lines
- Reverse Text
- Fancy Unicode Social Fonts (𝔉𝔞𝔫𝔠𝔶 𝔊𝔬𝔱𝔥𝔦𝔠, 𝘽𝙤𝙡𝙙 𝙎𝙖𝙣𝙨, Ⓒⓘⓡⓒⓛⓔ, 𝒮𝒸𝓇𝒾𝓅𝓉, 𝔻𝕠𝕦𝕓𝕝𝕖)

### 3. AI Magic Tools (Powered by Experiential Labs AI)
- ✍️ Fix Grammar & Spelling
- 👔 Professional Tone Enhancer
- 😊 Friendly / Conversational Tone
- 📝 Bullet Points Summarizer
- 🔄 Paraphraser / Rephraser
- 🚀 Text Expander & Elaborator

### 4. Monetization & AdSense Ready
- Built-in `ads.txt`
- Responsive Google AdSense placement containers
- Full Privacy Policy, Terms of Service, About Us, and Contact modals

## ⚙️ Deployment to Vercel

1. Push this folder to a new GitHub repository (e.g. `smart-text-utility`).
2. Go to [Vercel Dashboard](https://vercel.com/new) and click **"Add New Project"** -> Import your GitHub repository.
3. In Project Settings -> **Environment Variables**, add:
   - **Key:** `EXPLABS_API_KEY`
   - **Value:** `Your-Experiential-Labs-API-Key`
4. Click **Deploy**. Your new website will be live in seconds!
